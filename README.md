# Классификация новостей на AG News

Учебный проект по машинному обучению, в котором реализована простая модель классификации новостей на датасете AG News. Вся модель написана вручную на `NumPy`: загрузка данных, `forward pass`, `cross-entropy`, `backpropagation` и обновление параметров градиентным спуском.

## Описание задачи

Нужно классифицировать новости по четырём классам:

1. `World / политика`
2. `Sports / спорт`
3. `Business / бизнес`
4. `Sci/Tech / технологии`

Модель для текста из `T` слов:

```text
x = (1 / T) * sum(embedding(word_i))
y_hat = softmax(Wx + b)
```

Здесь `embedding(word_i)` — обучаемый вектор слова, `x` — средний вектор текста, `W` и `b` — параметры линейного классификатора.

## Используемый датасет

Основной источник данных: `AG News` через библиотеку `datasets`.

Если загрузка через `datasets` недоступна, в `data.py` предусмотрен резервный вариант чтения из локальных CSV-файлов.

## Описание модели

Модель состоит из трёх наборов обучаемых параметров:

1. Матрица эмбеддингов `E` размера `vocab_size x embedding_dim`
2. Матрица весов `W` размера `num_classes x embedding_dim`
3. Вектор смещений `b` размера `num_classes`

Для каждого текста:

1. Берутся embedding-векторы всех слов текста.
2. Считается их среднее.
3. Средний вектор подаётся в линейный классификатор.
4. Через `softmax` получаются вероятности классов.

## Краткое объяснение градиентов

Обозначим:

```text
e_i = embedding(word_i)
x = (1 / T) * sum(e_i)
z = Wx + b
p = softmax(z)
L = -log(p_y)
```

Тогда:

```text
delta = p - one_hot(y)
dL/dW = delta x^T
dL/db = delta
dL/dx = W^T delta
```

Так как:

```text
x = (1 / T) * sum(e_i)
```

то для каждого слова:

```text
dL/de_i = (1 / T) * dL/dx = (1 / T) * W^T delta
```

Если слово встретилось несколько раз, его градиенты суммируются.

## Почему embedding обучаются

Embedding-векторы — это такие же параметры модели, как `W` и `b`. При ошибке классификации градиент проходит через средний вектор текста обратно к embedding-векторам слов, которые встретились во входе. После этого embedding обновляются градиентным спуском и постепенно подстраиваются под задачу классификации.

## Чем embedding лучше Bag-of-Words

Embedding лучше `Bag-of-Words`, потому что:

1. embedding-векторы плотные, а `Bag-of-Words` обычно разреженный;
2. embedding имеют меньшую размерность;
3. embedding обучаются под конкретную задачу;
4. похожие по роли слова могут получить похожие векторы;
5. embedding обычно лучше обобщают на новые тексты;
6. `Bag-of-Words` хранит только частоты слов, а embedding — обучаемое представление слова.
