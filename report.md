# Лабораторная работа

## Тема: Классификация новостей на AG News

## 1. Цель работы

Цель работы состоит в том, чтобы реализовать простую модель классификации новостей на датасете AG News вручную на `NumPy`. В рамках работы нужно самостоятельно реализовать вычисление `forward pass`, функцию потерь `cross-entropy`, алгоритм `backpropagation` и обновление параметров градиентным спуском.

## 2. Описание датасета AG News

AG News — это датасет новостных заголовков и кратких описаний, разделённых на четыре класса. Он часто используется как учебный набор данных для задач классификации текстов.

В проекте используется уменьшенная выборка для быстрого запуска:

- `TRAIN_SIZE = 8000`
- `TEST_SIZE = 2000`

Тексты проходят простую предобработку: перевод в нижний регистр, удаление лишних символов, разбиение на слова, ограничение длины текста и замена редких слов на токен `<unk>`.

## 3. Классы классификации

Используются четыре класса:

1. `0 — World / политика`
2. `1 — Sports / спорт`
3. `2 — Business / бизнес`
4. `3 — Sci/Tech / технологии`

## 4. Математическая модель

Пусть текст состоит из `T` слов. Для каждого слова берётся обучаемый embedding-вектор:

```text
e_i = embedding(word_i)
```

Затем вычисляется средний вектор текста:

```text
x = (1 / T) * sum(e_i),  i = 1..T
```

После этого применяется линейный классификатор:

```text
z = Wx + b
```

где:

- `W` — матрица весов размера `num_classes x embedding_dim`
- `b` — вектор смещений размера `num_classes`

Вероятности классов вычисляются функцией `softmax`:

```text
p = softmax(z)
```

## 5. Функция потерь

Для правильного класса `y` используется `cross-entropy`:

```text
L = -log(p_y)
```

Для численной устойчивости в коде используется:

```text
softmax(z) = exp(z - max(z)) / sum(exp(z - max(z)))
```

и

```text
L = -log(p_y + eps), eps = 1e-8
```

## 6. Forward pass

Для одного текста `forward pass` выполняется так:

1. Берутся индексы слов текста.
2. Из матрицы `E` извлекаются embedding-векторы этих слов.
3. Вычисляется средний вектор текста `x`.
4. Считаются логиты `z = Wx + b`.
5. Применяется `softmax`, чтобы получить вероятности классов.
6. По правильной метке вычисляется функция потерь `cross-entropy`.

В коде это выглядит так:

```python
embeddings = E[word_indices]
x = np.mean(embeddings, axis=0)
logits = W @ x + b
probs = softmax(logits)
loss = cross_entropy(probs, y)
```

## 7. Backpropagation

Нужно вычислить градиенты функции потерь по всем обучаемым параметрам: `W`, `b` и embedding-векторам слов.

Обозначим:

```text
e_i = embedding(word_i)
x = (1 / T) * sum(e_i)
z = Wx + b
p = softmax(z)
L = -log(p_y)
```

Для комбинации `softmax + cross-entropy` удобно использовать выражение:

```text
delta = p - one_hot(y)
```

где `one_hot(y)` — one-hot представление правильного класса.

## 8. Градиент по весам W

Так как:

```text
z = Wx + b
```

то градиент по `W` равен:

```text
dL/dW = delta x^T
```

Это внешнее произведение вектора ошибки `delta` и вектора признаков `x`.

Градиент по смещению:

```text
dL/db = delta
```

## 9. Градиент по embedding-векторам слов

Сначала найдём градиент по среднему вектору текста:

```text
dL/dx = W^T delta
```

Но

```text
x = (1 / T) * sum(e_i)
```

Следовательно, вклад каждого embedding-вектора одинаковый:

```text
dL/de_i = (1 / T) * dL/dx
```

Подставляя `dL/dx`, получаем:

```text
dL/de_i = (1 / T) * W^T delta
```

Это означает, что каждый embedding слова получает часть градиента через средний вектор текста.

Если одно и то же слово встречается несколько раз, то соответствующие градиенты суммируются. Например, если слово встретилось три раза, его embedding получает сумму трёх вкладов:

```text
dL/de_word = grad_1 + grad_2 + grad_3
```

Именно поэтому в коде используется накопление градиента по индексу слова.

## 10. Реализация градиентного спуска

В проекте используется `Stochastic Gradient Descent` без готовых оптимизаторов. Для каждого текста выполняются:

1. `forward pass`
2. вычисление `loss`
3. `backward pass`
4. обновление `W`
5. обновление `b`
6. обновление embedding-векторов слов

Формула обновления параметров:

```text
parameter = parameter - learning_rate * gradient
```

Для модели это означает:

```python
W -= learning_rate * dW
b -= learning_rate * db
E[word_idx] -= learning_rate * dE_word
```

## 11. Почему embedding обучаются

Embedding-вектора являются параметрами модели так же, как `W` и `b`. При ошибке классификации градиент функции потерь распространяется не только на веса классификатора, но и на embedding-вектора слов, которые участвовали во входном тексте. После вычисления градиента embedding обновляются градиентным спуском. Благодаря этому слова, полезные для определения класса новости, постепенно получают такие векторные представления, которые помогают модели лучше разделять классы.

Например, слова, часто встречающиеся в спортивных новостях, постепенно будут сдвигаться в такие области embedding-пространства, которые помогают модели предсказывать класс `Sports / спорт`.

## 12. Чем embedding лучше Bag-of-Words

`Bag-of-Words` представляет текст как разреженный вектор частот слов. Такой подход не учитывает смысловую близость слов и не обучает компактные представления слов.

Embedding-подход представляет каждое слово плотным обучаемым вектором небольшой размерности. Эти векторы обновляются во время обучения под конкретную задачу классификации. Благодаря этому модель может выучить, какие слова важны для политики, спорта, бизнеса и технологий.

Основные преимущества embedding перед `Bag-of-Words`:

1. Embedding-векторы плотные, а `Bag-of-Words` обычно разреженный.
2. Embedding имеет меньшую размерность.
3. Embedding можно обучать под конкретную задачу.
4. Похожие по роли слова могут получить похожие векторы.
5. Модель с embedding обычно лучше обобщает на новые тексты.
6. `Bag-of-Words` хранит только факт появления слова, а embedding хранит обучаемое представление слова.
